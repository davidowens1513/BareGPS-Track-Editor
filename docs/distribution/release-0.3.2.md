# BareGPS Track Editor 0.3.2 — build 71

Multiple inputs remain visible together with stronger current-track styling, matching map/list name and colour indicators, and selection before editing. Unselected inputs use a 3-pixel line at 65% opacity. New imports become current and the map fits the inputs together.

The second-track import prompt sits at the opening button position. Its joined white X dismisses it; tapping the question also hides it even if the picker is cancelled. Settings can save a default input colour before importing.

Distribution: signed, non-debuggable Android APK/ZIP and iPhone Xcode source ZIP with prebuilt web assets. The iPhone bundle is not an IPA, App Store or TestFlight release. See [development and validation notes](../development.md) for development history and checks.
