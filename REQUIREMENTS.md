# BareGPS Track Editor requirements

This repository now provides the standalone red Track Editor. Route creation lives in the separate BareGPS Route Maker repository.

- Open directly into the import/edit workflow, without mode tabs.
- Preserve current import, input editing, simplification preview, original retention, plan assembly, confirmation, terrain, route-card and GPX export behaviour.
- Keep Settings and About specific to editing.
- Keep independent local workspace keys and stable platform identities.
- Maintain Android, iOS source and web preview builds.
- Show product-specific version, downloads and Git link under Tools at appsbyonzy.dev.

Current features, limits and outstanding release checks are documented in README.md.
